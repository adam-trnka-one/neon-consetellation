# Neon Space

A mobile-first, single-player real-time strategy game inspired by *Auralux: Constellations*.
Own planets passively generate units; select your planets and tap a target to send half their
units; capture every planet to win. Maps are procedurally generated from a seed, so there is
no level cap. Online multiplayer is planned for a later phase.

## Stack

- **Vite + React + TypeScript** with **TanStack Router** (file-based routes, per-route `head()` metadata)
- **Tailwind CSS 4** (CSS-first theme tokens)
- **Canvas 2D** game rendering — fixed-timestep deterministic simulation, additive glow sprites
- **Supabase** (anon key, no auth) for the global leaderboard

## Getting started

```sh
npm install
cp .env.example .env.local   # fill in Supabase credentials (optional)
npm run dev
```

Without Supabase credentials the game is fully playable; the leaderboard shows a
"not configured" state.

| Script | Purpose |
| --- | --- |
| `npm run dev` | dev server |
| `npm run build` | production build + typecheck |
| `npm test` | simulation unit tests (determinism, combat, victory) |
| `npm run typecheck` | TypeScript only (requires `src/routeTree.gen.ts`, generated by dev/build) |

## Routes

- `/` — landing
- `/play` — match setup (players 2–4, AI difficulty per slot, map size, optional seed)
- `/play/match` — the game; config lives in URL search params, so match URLs are shareable
- `/how-to-play` — rules + controls
- `/leaderboard` — global scores; tab/search/page/profile-drawer state is all in the URL
- `/settings` — nickname for the leaderboard
- `/privacy`, `/cookies`, `/terms` — legal pages (placeholder contact: privacy@neonspace.game)

## Architecture notes

- `src/game/sim/` — pure deterministic simulation stepped at 30 Hz (`step.ts` is the ruleset)
- `src/game/engine/` — `GameEngine` owns the rAF loop and publishes HUD snapshots to React via
  `useSyncExternalStore`; `input.ts` is the pointer-event state machine for desktop + touch
- `src/game/mapgen/` — Poisson-disc sampling + farthest-point start seeding, all from a
  seeded mulberry32 RNG (same seed ⇒ same map)
- `src/lib/consent/` — consent state in localStorage; `gate.ts#onConsentGranted` is the hook
  for loading any future analytics/marketing scripts only after opt-in
- `supabase/migrations/0001_leaderboard.sql` — schema, RLS, indexes, and the `get_rank`
  function. Scores are append-only; see the file header for the anon-key RLS tradeoff and
  the auth upgrade path.
